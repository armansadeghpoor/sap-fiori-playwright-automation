## Remaining decisions before retirement

* **G8:** historical rerun after source edits or incomplete sealed runs still differs. Current strict source/hash/identity and complete guards remain. A fresh discovered new Run is available but is not represented as an equivalent historical rerun.
* **G9:** custom VS Code `nodePath` is not a standalone Service runtime preference. Native artifact terminals do reuse that configured Node helper, but this does not resolve execution runtime parity.
* Workers remain fixed at **1** in both interfaces. Retries remain **0**, with `--no-deps`, `--forbid-only`, `--update-snapshots=none`; no nonexistent adjustable-workers feature is claimed.
* Report/Trace/archive actions require a compatible explicitly selected Bridge window. Pure standalone viewing without VS Code is still unavailable; validated downloads and Source Preview remain independent.
* Dirty checks cover registered reachable windows and selected spec files. Initial disconnected execution is explicitly saved-disk-only, never described as including unsaved editor buffers. Nonregistered editors/imported helper buffers and atomic editing across processes cannot be certified.
* Pattern-based log redaction cannot infer an unlabeled arbitrary secret printed by test code. Known credentials and common labeled/token formats are covered, overlong lines are omitted, and raw archived logs are not exposed by the new feature.
* Physical monitor/focus behavior and activation in the user's installed profile remain manual acceptance. No installation is performed.
* The previously observed intermittent Bridge reconnect failure remains a historical open risk unless reproduced and explained. Passing controlled reconnect checks do not establish its root cause.

## Verification entry points

`test/parity.test.cjs` covers cancellation, failed cleanup, dirty/reconnected/multiple windows, fixed artifact identities, copy isolation, attempt DTOs and bounded/redacted CLI streams. `test/parity-browser.cjs` drives Dashboard actions through native authentication into actual Playwright report/trace servers on fixture copies, verifies outside-path refusal, independent ZIP downloads, cancellation selection preservation and attempts. Expanded `test/run-bridge-vscode.cjs` + `bridge-vscode.cjs` use two real isolated Extension Hosts, two distinct Persian file paths, permanent tabs/reuse, column targeting, dirty and untitled documents, correct window and no fallback. The existing complete Studio validation remains mandatory.

## Release regression coverage for rows 22/23

The selected-Run refresh regression found in the final audit is fixed. `test/history-selection-browser.cjs` deletes the last selected synthetic Run and one selected Run with another remaining. It checks an empty/updated History, cleared old Summary/Inspector/attempts/source/artifacts/Rerun state, preserved spec bytes, and absence of error banners (including transient caught errors), JavaScript errors and unhandled rejections. The existing plan/confirm/Trash restore and security harnesses remain. No real History or Trash entry is used by these tests.
